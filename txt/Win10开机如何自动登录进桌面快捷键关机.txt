Win10开机如何自动登录进桌面

https://zhuanlan.zhihu.com/p/61262940

使用Win10的人都知道，系统默认每次开机都要用户登录和输入密码才能进入桌面。其实，这对于个人用户来说很麻烦，这里给大家分享一个小技巧，让Win10开机自动登录进桌面（适用于其他windows系统）。

1、开始-运行，或点击Cortana搜索框，输入netplwiz，打开用户账户面板；

2、点击当前使用的用户名，去掉“要使用本计算机，用户必须输入用户名和密码”复选框；

3、点击“确定”按钮，再次输入一次当前用户的登录密码；

4、设置完成后重新启动电脑，这时Win10就会自动跳过登录环节，直接进入桌面了。


Windows 10 使用快捷键关机的方法
https://jingyan.baidu.com/article/ce09321b53eb6c6afe858f55.html

在 Windows 10 中，可以通过多种快捷键快速执行关机操作，无需使用鼠标，适合需要高效关闭电脑的场景。

方法一：Ctrl + Alt + Delete

    按下 Ctrl + Alt + Delete 组合键。

    点击右下角的 电源按钮 图标。

    在弹出菜单中选择 关闭计算机 并确认。

方法二：Windows + X           **************

    按下 Windows + X 组合键。

    在快捷菜单中选择 关机或注销。 U键

    在弹出菜单中选择 关机。 U键

方法三：Alt + F4           **************

    确保当前处于桌面界面。

    按下 Alt + F4（部分笔记本需同时按 Fn 键）。

    在弹出窗口中选择 关机 并按 Enter。

方法四：Win + R 命令行

    按下 Win + R 打开运行窗口。

    输入 shutdown /s /t 0 并按 Enter。

方法五：自定义快捷键

    在桌面右键选择 新建 > 快捷方式。

    输入 shutdown -s -t 5（数字为延迟秒数）并点击 下一步。

    命名快捷方式并点击 完成。

    右键快捷方式选择 属性，在 快捷键 栏设置组合键（如 Ctrl + Alt + S）并点击 确定。
