禁用这 7 个 Windows 后台服务，电脑立刻起飞！从此告别卡顿 | 零度解说

在开始之前，我们需要先进入服务管理，通过快捷组合键：Win+R  打开命令框输入命令 services.msc

1. Connected User Experiences and Telemetry (连接用户体验和遥测服务)        ********
功能：该服务负责收集并向微软发送您电脑的使用情况和诊断数据，用于改进Windows的用户体验。

2. Windows Search (Windows 搜索)
功能：为文件、电子邮件和其他内容提供内容索引、属性缓存和搜索结果。

3. SysMain (曾用名 Superfetch)                                          ********
功能：通过分析用户的内存使用模式，将常用应用程序预加载到内存中，从而加快程序的启动速度。

4. Print Spooler (打印后台处理程序)                                     ********
功能：管理所有本地和网络打印队列，并控制所有打印工作。

5. Windows Biometric Service (Windows 生物识别服务)                      ********
功能：为应用程序提供捕获、比较、处理和存储生物识别数据的能力，支持指纹识别、面部识别等功能。

6. Remote Registry (远程注册表)                                         ********
功能：允许远程用户修改此计算机上的注册表设置。

7. Program Compatibility Assistant Service (程序兼容性助手服务)
功能：为应用程序兼容性助手提供支持，监视用户安装和运行的程序，并检测已知的兼容性问题。
