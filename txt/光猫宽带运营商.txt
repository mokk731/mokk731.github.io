256MB 里的老大哥：我们拆解了中国家用光猫的底层固件，在字节码里发现了什么？ (Static Firmware Autopsy)

在千家万户的弱电箱里，那台运营商免费赠送、理论上只负责“光纤转网线”的 256MB 内存家用光猫，为什么常年滚烫、CPU 占用率高达 60% 以上？
本期视频对两款国内主流运营商定制光猫的静态闪存固件进行了代码级反编译与配置审计。没有阴谋论，只有官方固件字节码与 XML 配置文件里的原始字符串：
1. 256MB 物理内存里常驻的 66 线程 Java OSGi 虚拟机（/usr/cmcc_app/bin/felix.jar），霸占超过 130MB 运存；
2. com.chinamobile.smartgateway.cmccdpi 核心类 Activator.class 里的四行英文告警日志——为什么哪怕光猫 CPU 严重过载，未满 20 次也绝不关闭 HTTP 与 TCP/UDP 监控规则？
3. 216KB 核心配置表 lastgood.xml 中硬编码的明文 HTTP MAC 上报协议，以及全国复用的一行共享密钥：MIB_MACINFO_REPORT_SHAREKEY="xinjiang_ctcc"；
4. 隐藏在 /opt/upt/apps 容器中的家庭拓扑测绘（xb01odmv3）与流量重定向劫持插件（redictv3）；
5. 绕过家庭防火墙的地下 46 号控制专网（TR-069 CWMP），以及如何通过纯桥接减负与开源软路由（OpenWrt）夺回家庭网络边界，将 300M 宽带从 290M 枷锁释放至 375.8M。

电信光猫 m01-b01-inner 插件是什么？改桥接能防住吗｜第159期 #光猫 #天翼网关 #中国电信

Telegram 频道（新视频第一时间发）：https://t.me/bufanchevpn

11 月 17 日，V2EX 一位网友从上海电信（中兴 ZXHN G7615V2）和浙江电信（ZN-XG120）两台光猫的进程内存里，导出了一个隐藏插件 m01-b01-inner 的解密源码（天翼网关 3.0 起，光猫里另有一个电信改造的 OpenWrt 容器，插件装在里面，管理页面看不到，也关不了）。

插件真正的代码是加密的 Lua 脚本，开机解密进内存后马上删除明文，所以过去几年网上只停在"疑似上报 MAC"。
默认开着的 xid 模块：从经过光猫的明文 HTTP 请求（网址、来源页、Cookie）里抓手机号、IMEI、IMSI、MEID、OAID、AndroidID、IDFA、IDFV、经纬度、手机型号，用正则校验（1 开头第二位 3–9 的 11 位数字当手机号，460 开头 15 位当 IMSI），合并重复后每 30 分钟上报。
每条上报都带光猫序列号和宽带注册码（LOID），一个 LOID 对应一个实名宽带账户。数据 gzip 压缩、AES 加密后发往 189cube.com 的服务器。
默认还开着：家里所有设备的清单（MAC、IP、主机名、品牌型号、系统、上下线时间、流量）、App 使用统计。
默认关着、服务器一条配置就能打开的：shell（以 root 执行服务器发来的命令并回传结果）、pscan（从服务器下载扫描程序扫整个局域网，参数和 nmap 一致）、记录完整网址和 Cookie、HTTPS 域名、DNS、连接五元组、原始数据包、302 网页跳转、从任意网址下载新代码替换自己。
作者续帖：上海版插件还有一个默认关着的模块，从东方财富、同花顺、问财、雪球的网址里取股票代码，按设备记看了哪只、几次、多久。
作者原话：你的光猫今天做什么，取决于电信服务器今天给它发什么。
更正：第 156 期我们说"电信那份固件里没找到记录网站的代码"。原因是电信的业务代码加密存放、加载完就删，光看固件文件找不到。

它看得见什么：HTTPS 只看得见域名；明文 HTTP 的网址、Cookie、里面夹带的手机号全看得见；开着翻墙软件时，最多看见某台设备连了某个服务器。

能做的：
1. 光猫改桥接，用自己的路由器拨号（打 10000 或找装维师傅，先问清宽带账号密码；有 IPTV 的要在路由器上设置，作者另有教程）。
2. 改不了桥接，光猫后面接自己的路由器，光猫分不清是哪台手机，但网址和明文里的手机号照样经过它。
3. 翻墙开 TUN 模式或在路由器上翻墙，DNS 用加密的，用不翻车网站的 DNS 泄漏检测确认。
4. 不教 telnet 删插件：插件会被重新下发，弄坏了要去营业厅换。
5. 按《个人信息保护法》第 45 条，书面要求运营商告知处理了你哪些个人信息。

宽带送的光猫，把你家每台手机上的网站记下来明文发走｜第156期 #光猫 #中国移动 #DNS

Telegram 频道（新视频第一时间发）：https://t.me/bufanchevpn

中国移动光猫里装着一个叫"软探针"的插件（cmccdpi，安装包名里带 DPI，深度包检测）。我们查了网友公开的两份移动光猫固件：一台诺基亚贝尔（系统 2020 年，插件 2.2.2），一台中兴 F7005MV3（插件文件日期 2024 年 5 月，版本 4.3.2，另有广东专用版 4.3.1）。

插件每条记录里同时写：域名、终端 MAC 地址、开始时间、持续时间、上下行流量；另有一份 DNS 查询记录（查的域名、DNS 服务器、请求和响应时间）。
光猫里的镜像程序把经过的 TCP 连接复制一份交给插件，复制规则是插件自己加的，目的地是光猫自己（127.0.0.1:50000）。
报告发往 http://（服务器）/rest/cmcc_softprobe/home_gateway/periodicmessage，没有 https。老版本默认十分钟一次，服务器可以改，最快两分钟。
我们用老版插件自带的发送代码在自己电脑上回环收了一次（测试数据），收到的就是原样的 JSON。
服务器表写死在插件里：老版 32 个地址、每省一个，8 个就是移动自己的域名（*.chinamobile.com、广东 gmcc.net）；新版每省三个，共 94 条，多出来的是 111.63.81.x 和 117.128.5.x 两个网段。抽查 whois 都是中国移动 CMNET。
两个版本都带着 AES_ECB、AES_CBC 两个加密模块，两个版本里都没有任何地方调用它们。新版 https 仍是 0 处。
收的东西两版基本一样（Wi-Fi 邻居、宽带流量老版就有），新版多了几项连接统计。
公开的光猫测试培训资料里写着"移动软探针插件数据流镜像、dns访问信息测试方法"，对照《中国移动智能家庭网关软探针北向接口技术规范 V4.3.0》。
电信（中兴 F7607P 电信版，2023）：cloudclient 会上报下挂设备清单（设备名、类型、MAC、局域网 IP、品牌、系统），RSA＋AES 加密，和 2022 年版是同一个文件。联通（中兴 F7607P 联通版，2022）：上报设备名、MAC、上下行网速。这两份里没找到记录访问网站的代码。

查不出来的：你家光猫装没装、开没开（按省份配，看服务器下发）；报上去以后存多久、谁能看；我们查的是网友公开的这几台，没有真机抓包。

能做的：翻墙软件开 TUN 模式或在路由器上翻墙，让 DNS 也走进去，用不翻车网站的 DNS 泄漏检测确认；没开翻墙软件时，安卓私人 DNS 填加密的（阿里、腾讯都支持），管一半；光猫后面接自己的路由器，只能让光猫分不清是哪台手机，上了哪些网站照样看得见。
